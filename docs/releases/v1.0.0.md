# 🌲 Buckthorn v1.0.0 — Production C11 & Cython Web Engine

We are excited to announce the general availability of **Buckthorn v1.0.0**, a compiled C11 and Cython web framework engineered for ultra-low-latency Python APIs, microservices, and real-time WebSocket systems.

Buckthorn v1.0.0 pairs a FastAPI-style type-annotated Python developer experience with a zero-ASGI C11 core powered by `libuv`, `picohttpparser` (SSE4.2), Redis `rax`, `yyjson`, OpenSSL `libcrypto`, and a lock-free C11 `<stdatomic.h>` ring logger.

---

## ✨ Highlights in v1.0.0

### 🚀 C11 & Cython Execution Engine
- **Native `libuv` HTTP/1.1 & WebSocket Server (`bt_http.c`):** Supports multi-packet TCP stream reassembly, mixed sync/async HTTP/1.1 request pipelining, non-blocking `uv_try_write` fast paths, `SO_REUSEPORT` multi-worker process supervision, and live RFC 6455 WebSocket `101 Switching Protocols` upgrades with 64-bit XOR frame unmasking.
- **Per-Connection 64KB Bump Arena (`bt_arena_t`):** Eliminates per-request heap fragmentation with $O(1)$ pointer-bump allocations, dynamic overflow slabs for large payloads, and automatic arena lifetime extension across suspended `async def` coroutines (`BT_HANDLER_SUSPENDED`).
- **Zero-Copy `yyjson` Schema & Nested Model Pipeline (`bt_json.c`, `_core.pyx`):** Full support for flat and nested `Schema` models and `list[Schema]` arrays using thread-local 64KB pools, $O(1)$ ordered iterator lookups (`yyjson_obj_iter_getn`), 2-node `NOESC` key writers, and direct-to-arena `yyjson_mut_write_buf` serialization.
- **Compile-Time Flattened Dependency Injection (`app.py`, `_core.pyx`):** Resolves `Depends()` DAGs at route registration time into a flat linear execution array with CPython 3.11+ `PyIter_Send` eager coroutine stepping (zero `StopIteration` exception unwinding) and LIFO sync/async generator teardown.
- **Cache-Line-Isolated Lock-Free `RingLogger` (`bt_logger.c`):** 64-byte cache-line-aligned (`_Alignas(64)`) SPSC ring buffer with producer-cached `read_idx`, background `pthread` batch `writev()` flushing, `os.fork()` worker self-healing, and graceful shutdown draining.
- **Ahead-of-Time AST-to-Cython Compiler (`buckthorn build --prod`):** Lowers Python `Schema` classes into `@cython.freelist(4096)` `cdef class` extension types, elides non-awaiting `async def` functions into synchronous C calls, and compiles application modules into native `.so` binaries.

### 🛡️ Hardened OWASP ASVS & RFC 9112 / 8259 Security
- **HTTP/1.1 Framing & Smuggling Guards:** Strict rejection of `Transfer-Encoding` smuggling vectors, duplicate `Host`/`Content-Length` headers, `obs-fold` continuations, header-colon whitespace, and `Content-Length` body mismatches.
- **15-Second Slowloris Timer (`uv_timer_t`):** Per-connection idle and partial-read timeouts automatically close stalled sockets and reclaim arena memory.
- **Strict Input & Numeric Validation:** C-level URL percent-decoding (`%XX` and `+`), path traversal and double-encoding (`%25`, `%2e`, `%2f`, `%5c`, `%00`) blocks, `yyjson` 64-level depth limits, embedded `\u0000` string rejection, `uint64_t` wrap-around guards, and IEEE-754 `NaN`/`Infinity` rejection.
- **Constant-Time C Security (`bt_security.c`):** C-level HS256 JWT verification (`exp`, `nbf`, `scopes`), API Key (header/query), and HTTP Basic Auth using length-hiding OpenSSL `SHA256` + `CRYPTO_memcmp` comparisons.
- **Tier-1 C Middlewares (`bt_middleware.c`):** Zero-GIL `TrustedHostMiddleware`, `CORSMiddleware` (`OPTIONS` preflight fast-return), `SecurityHeadersMiddleware`, and collision-hardened `FNV-1a` `RateLimitMiddleware`.

### 📦 Developer Experience, Typing & Packaging
- **PEP 561 Type Stubs:** Full `buckthorn/_core.pyi` and `buckthorn/py.typed` support for `pyright`, `mypy`, Zed, and VS Code autocomplete.
- **Zero-Dependency Hot Reload:** `buckthorn dev main:app --reload` watches `.py`, `.pyx`, `.pxd`, `.c`, and `.h` files via fast `scandir` mtime snapshots.
- **Portable Binary Wheels (`cibuildwheel`):** Pre-built wheels for Linux (`manylinux_2_28_x86_64`, `manylinux_2_28_aarch64`) and macOS (`x86_64`, `arm64`) across Python 3.11, 3.12, 3.13, and 3.14.
